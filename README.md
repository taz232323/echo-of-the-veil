# The Echo of the Veil Website

Static GitHub Pages-ready website concept for **The Echo of the Veil** by **J. A. Jacobs**.

## Files

- `index.html` - single-page website
- `styles.css` - responsive styling
- `script.js` - mobile navigation, edition tabs, newsletter demo, scroll reveals, particles
- `echo-of-the-veil-cover.jpg` - book cover image
- `favicon.svg` - site icon

All files live at the top level (no subfolders), so paths work the same locally and on GitHub Pages.

## Run Locally

Open `index.html` in a browser. No build step, package install, or server is required.

## GitHub Pages

Upload every file in this folder to the **root** of a GitHub repository (keep them flat — do not nest them inside a subfolder), then go to **Settings → Pages** and set the source to **Deploy from a branch**, branch `main` / `(root)`.

The Amazon button points to:

`https://www.amazon.com/Echo-Veil-J-Jacobs/dp/B0GYZ4T7Q2/`

The Bookshop, Barnes & Noble, and indie retailer buttons are placeholders and should be replaced with final retailer URLs before launch.
